# بوابة القرآن الكريم وعلومه

واجهة عربية RTL حديثة لقارئ القرآن الكريم، مبنية على التصميم المرجعي المرفق، وتجمع بين المصحف والتفسير والتلاوات والإذاعات والدروس والتقويم الهجري.

## ما الذي تم ربطه؟

الموقع يجلب البيانات الحية من واجهات عامة بلا مفاتيح سرية: قائمة القراء والتلاوات من MP3Quran، الإذاعات الإسلامية من Islamic Radio API، كتب وتفاسير الآيات من Quranpedia، الخطب والدروس من Islamic Network Sermons، والتاريخ الهجري من AlAdhan. توجد تفاصيل الروابط وسياسة التخزين المؤقت في [API_SOURCES.md](./API_SOURCES.md).

## التشغيل محليًا

```bash
npm start
```

ثم افتح `http://localhost:3000`. الموقع ثابت ولا يحتاج إلى قاعدة بيانات أو متغيرات بيئية.

## ملاحظات النشر

الموقع مناسب لـ GitHub Pages أو أي استضافة ملفات ثابتة. ملف `manus-routes.json` مخصص لمعاينة Manus، بينما أمر البناء في إعدادات المشروع ينسخ `index.html` و`public/` إلى `dist/`.

المحتوى يُقرأ مباشرة من المصادر الأصلية ولا تُخزّن قواعد البيانات محليًا. بعض روابط البث قد تختلف قابليتها للتشغيل حسب بلد الزائر أو دعم المتصفح لبروتوكول البث.
